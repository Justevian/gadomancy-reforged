# Gadomancy: Reforged

[Русский](README.md) · **English**

An unofficial port of **Gadomancy 1.7.10** to **Minecraft 26.3** on **NeoForge**. This add-on requires [Thaumcraft 4: Reforged](https://github.com/notlikethiss/thaumcraft-4-reforged) and adds its own tab to the Thaumonomicon.

## Features

- **Essentia storage.** Upgrade the Essentia Condenser with Elements of Darkness to store up to 3,000 units per aspect. Sticky jars mount on walls and ceilings, and linked remote jars distribute essentia between them.
- **Automation.** Arcane Dropper, Arcane Packager, and Infusion Claw.
- **Aura and nodes.** Aura Pylon, Node Manipulator, and foci for changing nodes or opening a gate.
- **Golems and familiar.** Break and Bodyguard cores, silverwood golems, and an ethereal familiar with elemental upgrades.

## Installation

1. Set up **Minecraft 26.3** with **NeoForge 26.3.0.102**.
2. Download **Gadomancy 0.1.21-alpha** from [Releases](../../releases).
3. Put the JAR in your `mods` folder alongside **Thaumcraft 4: Reforged 1.1.3** for Minecraft 26.3 and **TerraBlender 26.3-26.3.0.0.9**.

[Download Thaumcraft 4: Reforged](https://github.com/notlikethiss/thaumcraft-4-reforged/releases/tag/26.3)

## Building from source

Install **JDK 25** and put `thaumcraft-4-reforged-1.1.3-26.3.jar` in the repository's `libs` folder. Run `./gradlew build` or `.gradlew.bat build` on Windows. The JAR is written to `build/libs`.
